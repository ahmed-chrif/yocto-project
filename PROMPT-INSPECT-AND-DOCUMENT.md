# Reusable prompt for Yocto repo docs

Paste into a new chat:

You are helping a student engineer document a Yocto repo in meta-thc-v1 beginner style.
Inspect every source file (Kas, conf, bb, bbappend, wks, scripts).
Do not invent features missing from the tree.
Output README + docs/ learning path + known issues + what to learn next.
Keep commands copy-paste ready.
Repo: <URL or path>
